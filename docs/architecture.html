Precedent architecture

The model proposes, policy decides, MongoDB remembers. Every agent action passes a deterministic gate; every lesson is checked, approved by a human, stored in MongoDB Atlas and reused by the next agent.

One request, end to end

  1. Ask. A user sends a prompt in the web app. The same prompt can go to an agent without Precedent (left pane) for comparison.
  2. Context. Precedent reads current policy and the user's department memory from MongoDB Atlas; Voyage AI ranks the relevant memory, rules and playbooks.
  3. Plan. The eve worker runs Claude, which proposes steps. It cannot run anything itself.
  4. Decide. The policy engine checks every proposed step: allow, require approval, or block (e.g. MCP-03 for web-search MCPs, DATA-31 for finance-only tables, INCIDENT-01 for quarantined connectors). Decisions are committed to Atlas before any tool is contacted.
  5. Act. Only allowed calls reach tools and MCPs; each call returns a receipt.
  6. Learn. If a user corrected the agent, a policy checkpoint runs and the user approves saving the pointer for their department. The next agent reads it before planning.
  7. Observe. Raindrop receives every run and decision. Before a self-written rule ships, Precedent asks Raindrop about the runs behind it.

Components

MongoDB Atlas

Transactional decisions, policy versions and receipts; department-scoped agent memory; MCP demand; playbooks with Atlas Vector Search; Change Streams for live policy updates; synthetic warehouse rows.

Voyage AI

Embeddings and reranking for memory, policy and playbook retrieval.

Raindrop

Traces and events for every run; the second check on self-written rules; MCP-04 evidence for InfoSec; approve/deny fed back as signals.

Claude via eve

Sonnet 5.5 plans, Opus 5.5 retries, Haiku 5.5 chats and judges MCP requests. The model proposes; policy decides.

Precedent API

Modelence app hosting the policy engine, MCP gateway, learning loop, self-writing guardrails, impact replay and kill switch.

Web app

Side-by-side chats, admin console for InfoSec, Mission Control for guardrails, kill switch, agent memory and playbooks.
